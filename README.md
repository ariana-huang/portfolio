# Ari Huang · Portfolio

Personal portfolio site for Ariana Huang: work experience, projects, a monthly Now page, hobbies and interests.

Static site with no build step. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works out of the box).

- `index.html`: the whole site (pages are hash routes: `#work`, `#projects`, `#now`, `#interests`, `#connect`)
- `resume.pdf`: résumé offered by the download buttons
